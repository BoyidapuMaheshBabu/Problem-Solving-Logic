## 🔍 Problem-Solving Approach

I use this repository to practice solving problems that I have **not solved before**.

```text
Understand the requirements
          ↓
Try to solve the problem independently
          ↓
Identify missing knowledge
          ↓
Learn the required concept
          ↓
Design my own approach
          ↓
Implement
          ↓
Test & debug
          ↓
Review & improve
```

When a problem requires a concept I have not learned yet, I may use AI to **learn and understand that concept**.

After understanding it, I return to the problem and develop my own approach and implementation.

AI may help me learn a concept, but I do not use AI-generated final solution code as my answer to these problems.

## 🔄 Refactoring & Improvement

As my understanding improves, I may revisit an earlier solution and add a **refactored solution** when there is a meaningful improvement in readability, structure, validation, reuse, or maintainability.

The original solution is kept because it represents an earlier stage of my thinking.

```text
Original Solution
       ↓
Review
       ↓
Identify Improvements
       ↓
Refactor
       ↓
Compare
       ↓
Learn
```

The goal is not to hide earlier work, but to make the progression visible.
