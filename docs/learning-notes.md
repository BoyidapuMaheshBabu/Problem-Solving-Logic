# Contributing

This repository is primarily a personal learning project focused on Python problem solving and logical improvement.

## How to contribute

- Suggest new problem ideas
- Improve existing explanations or formatting
- Share cleaner refactors or better edge-case handling
- Report issues in problem statements or documentation

## Contribution guidelines

1. Keep solutions readable and educational.
2. Prefer clear naming and simple logic over unnecessary complexity.
3. Preserve the learning structure of each problem.
4. Add useful comments only when they improve understanding.
5. Keep documentation professional and consistent.

## Pull requests

Open a pull request with a clear description of:

- what changed
- why it was improved
- whether it affects a problem explanation, code, or repo structure

---

This project values quality, clarity, and continuous learning.
